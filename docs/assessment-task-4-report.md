## Delivered scope

The fifth navigation surface, Deliverables, consumes saved workspace state. Its Export basis selector chooses the current saved draft or an exact timestamped recommendation snapshot. Unsaved form values and temporary what-if/simulation results do not enter the payload. Internal notes start excluded. The actual Markdown preview and all three download buttons consume the same prepared payload. Concurrent generation is prevented; all download/selection controls are disabled while running, errors provide retry/backup guidance, and Blob URLs are revoked after browser download.

`src/modules/assessment/exports.ts` is the public facade. Focused modules under `exports/` own the explicit payload, brief, workbook and slides. Public functions are `prepareExport(engagement, opportunityId, brand, options)`, `investmentBrief(payload)`, `createSteeringPack(payload)`, `createAssessmentWorkbook(payload)` and `downloadArtifact(blob, filename)`. `prepareSelection` also accepts the existing typed selection boundary from `ui/surface.ts`. `options.snapshotId` is optional; `includeInternalNotes` defaults to false. Unknown/missing selected IDs fail with actionable errors, rather than silently switching the export basis.

The payload projects allowlisted facts, validation, reviewed source records, assumption revision history, cost and benefit lines, source requests, policy reasons/readiness and independent all-option calculations. Raw histories, recursive recommendations and unknown legacy objects never enter the serializers. The only opted-in private field is evidence `internalNote`. There is no generic raw-record JSON stored in metadata or hidden artifact contents. Snapshot facts, assumptions, currency and narrative are self-contained. Only the current opportunity revision is supplied separately for the stale marker. Workspace brand is an explicit current rendering input, because historical snapshots do not capture it.

Each alternative calls the existing deterministic engine against its captured BAU. The saved selected base is the scenario basis. Annual capacity/benefits, first-year OPEX/ROI, 36-month economic/cash NPV, sustained monthly payback, zero-NPV adoption and negative maximum viable investment retain the engine's conventions. Sensitivity uses the same engine and reports invalid perturbations instead of fabricating values. Cash is a subset; unknown is Not assessed, zero remains numeric zero, and a complete but unattained payback/undefined ROI is explained separately.

Controller ruling: an incomplete historical Investigate recommendation retains its original reviewed narrative/outcome and is labelled **Reviewed recommendation snapshot — incomplete assessment / draft economics** in every format and preview. The selected incomplete economics never become investment-ready. A current case is always **Draft / not reviewed**. This resolves the task's draft-economics restriction without erasing legitimate reviewed history.
